# 需求与台词库 v2（命题版）

> 命题：**设计师站在信息链末端，接收所有人互相矛盾、不断变化、无法准确表达的要求，却要为最终结果负责。**
> r1 = 需求的不可表达性 ｜ r2 = 要求的自相矛盾性 ｜ r3 = 系统的替代性
>
> ⚠️ 这是新版本，原版保留在 `需求与台词库.md`，未做任何改动。
> 选项 ID（A/B/C/D、A1~A4、C1~C3、R3A~R3D）、flag（saved / sneaky / trust / money / twoVersions）、
> 死法编号（No.001~005）、结局 key（hand / chaos / ignore）**全部不变**，可整段对照同步进 `src/game/script.ts`。
> 说话人标记：【李总】【Ray】【系统】【你】

## DAY 1 · 需求 1：再大一点（不可表达性）

【系统】派单流转：市场部 → 李总 → 你
【系统】原始需求：「要有大气感」（转发自：李总微信语音，2'17"）
【系统】备注：李总原话：「你懂我意思吧？」

【李总】辛苦辛苦，在忙吗？
【李总】海报初稿看了。整体……怎么说呢，差点意思。
【李总】要大气，要国际化。我们明年可是要去纳斯达克敲钟的。
【李总】⚠️ 具体怎么弄，你们专业的看着办。反正——再大一点。

【系统】你没有收到参考图、尺寸要求或任何书面定义。「大气」没有翻译件。

| 选项 | 反应 |
|---|---|
| A 照做：往大里猜 | 你：Logo 30%→62%。李总：哎呀——对！就是这个感觉！国际化！改完这单给你加鸡腿 🍗。系统：没有人知道「国际化」和「大」之间的关系。包括李总。Ray（私聊）：大群里我就不说什么了。Logo 把产品挡住了。算了，年费到账就好。 |
| B 坚持专业（funnel） | 你：视觉层级会——李总：我不懂这些专业的。你就告诉我，能不能，再，大，一，点？辛苦啦！系统：他承认自己无法表达，但责任仍在你。Ray（私聊）：别跟他讲道理。他签的是年费合同。 |
| C 偷做两个版本 | 你：提交放大版，文件夹深处留下 v_专业版.psd。李总：这版可以！国际化！就它了！系统：他选了哪版、另一版会不会被看到，你永远不会知道。 |
| D 探讨设计理论 ☠️No.001 | 你：我们先把「大气」定义清楚——李总：……麻烦把你们总监电话给我一下，谢谢。系统：你试图澄清一个无法表达的需求。系统惩罚了试图澄清的人。 |

【李总】⚠️ 两个意见都要落实。你们设计师不就是干这个的？

【系统】提示：老板要「更大」，儿子说「不行」。两个需求互为否定，且都有截图为证。你将对最终结果负责。

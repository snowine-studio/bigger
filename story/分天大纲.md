# 分天大纲

## 整体结构（当前 demo）

```
开场屏（跑马灯 + BGM +「开始」）
  └─ 前情 1/4：Q邮邮箱收 offer（可逛：垃圾箱病毒死 / 求职投递 46 封拒绝信 / 三个附件）
  └─ 前情 2/4：当晚发朋友圈「新的开始 💪」（分组可见）
  └─ 前情 3/4：闹钟从 9:00 调到 7:00
  └─ DAY 1 上班：三轮需求
       ├─ 需求 1：Logo 再大一点（选择决定分支）
       ├─ 需求 2：A 线「儿子与老板」/ C 线「发错的那版」
       └─ 需求 3：智稿 AI 接入
  └─ 结局：5 个生存结局 / 6 种死法（随时可能触发）
```

## 每"天"的结构模板（以后新天照这个写）

1. **开场事件**：今天的离谱由头（一封邮件 / 一条通知 / 一个新人出现）
2. **三轮需求**：每轮 = 客户派单 + 3~5 个选项（含 1 个死亡选项、1 个 funnel 选项、1 个隐藏 flag 选项）
3. **系统变量**：当天世界发生的变化（DAY 1 是"AI 接入"），让"系统变了，需求没变"
4. **结算**：生存结局 + flag 尾声 + 图鉴更新

## DAY 2（需求 1 已起草，完整文案见 `需求与台词库_v2.md`）

  - D 问到底：请他定义「感觉对」（死 No.006 问到底死）
- **需求 2：五星好评（r1 × 评分机制）**：满意度系统首日，李总打了 4.0，让你自己找丢掉的那 1 分（差评理由栏：空）

  - B 加班重做（flag: overtime）→ 4.0 不变，「能加班解决的问题就不是问题」
  - C 上土味挂件（flag: tacky）→ ★5.0「要的就是这个设计感！」Ray 去阳台站一会儿
  - D 向系统申诉（死 No.007 申诉死）

  - C 拒绝比稿（funnel，谎称公司有付费规定）→ 评分 3.5，「自己人 = 可以免费使用的人」

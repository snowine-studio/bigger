# 《再大一点》故事工作区

剧情、台词、人设都写在这个文件夹里，**和代码分离**。
白天在手机上随手改这里，晚上回来跟 Kimi 说「读一下 story/」，它就会把新内容实现进游戏。

## 手机上怎么改

1. 浏览器打开 `github.com/snowine-studio/bigger`（或 GitHub App）
2. 进 `story/` 文件夹，点任意文件 → 右上角铅笔图标 ✏️
3. 改完拉到底，点 **Commit changes**，搞定

有零碎想法不想翻文件？直接开 **Issue**（仓库首页 → Issues → New issue），写一句都行。

## 文件说明

| 文件 | 写什么 |
|---|---|
| `世界观与人物.md` | 调性铁律 + 李总 / Ray / 你 / 其他人的设定 |
| `分天大纲.md` | DAY 1 已实现结构 + DAY 2 及以后的空白框架 |
| `需求与台词库.md` | 所有派单、选项、台词的完整文案（改文案改这里） |
| `死法与结局.md` | 一万种死法清单 + 五个生存结局 + 新死法投稿模板 |
| `灵感箱.md` | 任何点子，一句话也行，不设门槛 |
